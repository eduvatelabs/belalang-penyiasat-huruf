# Belalang Si Penyiasat Huruf · Episod 1

App buku cerita interaktif untuk murid prasekolah dan Tahun 1: mengenal dan menulis huruf kecil a–z bersama Belalang, berlatarkan cerita rakyat Pak Belalang.

**Main sekarang:** https://eduvatelabs.github.io/belalang-penyiasat-huruf/

## Kandungan
1. Lagu tema
2. Babak 1 & 2: Binatang kampung hilang, Kitab Huruf ditemui
3. Kenal huruf a–z (nama, bunyi, perkataan)
4. Surih huruf a–z dengan bintang, setiap huruf menemui satu barang yang hilang
5. Babak 3: Titah dari istana (bersambung ke Episod 2)
6. Sijil Penyiasat Huruf Kecil

Berfungsi di komputer, tablet dan telefon (paling selesa dalam mod landskap). Sentuh buku untuk mula; bunyi dimainkan selepas sentuhan pertama.
